
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa um jogo da Forca em Python para praticar manipulação de strings, loops, condicionais e entrada de dados. O jogador deverá adivinhar uma palavra oculta antes de esgotar as tentativas disponíveis.

## 📝 Tarefas

### 🛠️ Implementar a Mecânica de Adivinhação

#### Descrição
Crie a lógica principal do jogo: selecione uma palavra de uma lista predefinida e permita que o jogador tente revelá-la por meio de palpites de letras.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Mostrar as letras ainda não adivinhadas como espaços em branco, por exemplo, `_ _ _`.
- Aceitar palpites de letras e atualizar o progresso da palavra após cada palpite.

### 🛠️ Controlar as Tentativas e o Resultado

#### Descrição
Gerencie as tentativas incorretas e encerre a partida quando o jogador adivinhar a palavra ou não tiver mais tentativas disponíveis.

#### Requisitos
O programa concluído deve:

- Rastrear e exibir o número de tentativas incorretas restantes.
- Encerrar a partida quando a palavra for adivinhada ou as tentativas se esgotarem.
- Exibir uma mensagem indicando se o jogador venceu ou perdeu.
